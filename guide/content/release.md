# App version and updates

## Find your version

The app version appears on the login screen, desktop sidebar, and More footer. More also shows the UTC build timestamp.

A label such as v1.0.0 with a short revision identifies the frontend build. Modified means the build included uncommitted source changes. Unidentified build means Git metadata was not available or supplied at build time.

## Before reporting a difference

1. Record the version and build revision.
2. Refresh the app and confirm you are on the expected deployment.
3. Compare the guide with the available screen controls.
4. Ask the administrator whether the deployed frontend and backend include the feature.

## Coverage and change management

These guides cover repository behaviour reviewed on 19 November 2026. Source review is not proof of live deployment, physical-device acceptance, or a working Zoho account.

Documentation changes belong in version control alongside the app. Update affected task guides whenever a screen, permission, status, or integration boundary changes.

The initial help-centre release covers access, stock requests, approvals, shortage purchases, receiving, warehouse maps, equipment loans, trips, and troubleshooting.
